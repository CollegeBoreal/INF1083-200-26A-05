Ce cours permet de développer des compétences en développement d'applications hybrides et web.

Les principaux sujets abordés comprennent :

- les applications web, natives et hybrides ;
- la création et la configuration de projets ;
- le développement d'interfaces graphiques ;
- la programmation des interactions utilisateur ;
- la connexion des applications aux données ;
- la validation des entrées utilisateur ;
- le débogage et les bonnes pratiques de développement ;
- la documentation technique.
