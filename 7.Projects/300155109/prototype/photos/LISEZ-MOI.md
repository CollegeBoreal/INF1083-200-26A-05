# 📸 Photos des coiffures

Dépose ici des photos **libres de droits**, au format `.jpg` et **carrées si possible** (environ 600 × 600 px), avec **exactement** ces noms :

| Fichier | Prestation |
|---|---|
| `banniere.jpg` | Bannière de l'accueil (photo large, ex. 1200 × 600 px, de knotless braids) |
| `coupe-brushing.jpg` | Coupe + brushing |
| `brushing.jpg` | Brushing / mise en plis |
| `chignon.jpg` | Chignon de cérémonie |
| `coupe-homme.jpg` | Coupe homme |
| `degrade.jpg` | Dégradé (fade) |
| `box-braids.jpg` | Box braids |
| `knotless-braids.jpg` | Knotless braids |
| `nattes-collees.jpg` | Nattes collées (cornrows) |
| `twists.jpg` | Twists sénégalais |
| `depart-locks.jpg` | Départ de locks |
| `entretien-locks.jpg` | Entretien locks (retwist) |
| `coloration.jpg` | Coloration complète |
| `balayage.jpg` | Mèches / balayage |
| `defrisage.jpg` | Défrisage |
| `soin-hydratant.jpg` | Soin hydratant cheveux crépus |
| `lissage-bresilien.jpg` | Lissage brésilien |
| `coupe-enfant.jpg` | Coupe enfant |
| `tresses-enfant.jpg` | Petites tresses enfant |
| `barbe.jpg` | Taille de barbe |

S'il manque une photo, l'application affiche simplement l'emoji de la catégorie.

**Où trouver des photos libres de droits :** [Unsplash](https://unsplash.com) ou [Pexels](https://www.pexels.com).
Cherche par exemple « box braids », « locs », « fade haircut », « silk press », puis clique sur **Télécharger** (Download).
Ces deux sites permettent d'utiliser leurs photos gratuitement, même sans les citer, mais c'est une bonne pratique d'indiquer le nom du photographe.

> Les mêmes fichiers servent à l'application NativeScript : copie-les aussi dans `BelHair/app/photos/`.
