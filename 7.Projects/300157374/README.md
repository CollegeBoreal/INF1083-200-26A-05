# TOQUÉ — Carnet de recettes

Yanis Nait Idir · INF1083 · 300157374

Le carnet propose trois pages reliées par le routeur Angular : catalogue et filtre des favoris, fiche détaillée, ajout de recette. Les recettes personnelles et les favoris sont conservés sur l’appareil avec ApplicationSettings.

Patron : NativeScript Angular Blank. Modules utilisés : @nativescript/angular pour la navigation et les formulaires, @nativescript/core pour le stockage local. Aucun plugin tiers additionnel.

## Lancement dans PowerShell

Depuis ce dossier étudiant :

```powershell
cd b300157374
npm.cmd install
ns run android
```
