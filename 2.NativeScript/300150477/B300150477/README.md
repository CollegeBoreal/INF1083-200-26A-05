# B300150477 — Rois amazighs de Numidie

Application mobile NativeScript et Angular consacrée à quelques souverains numides liés à l’histoire de l’actuelle Algérie. Les fiches présentent Syphax, Massinissa, Micipsa, Jugurtha et Juba Ier.

## Fonctionnalités

- Liste de souverains avec leur période et leur territoire.
- Fiches détaillées accessibles depuis la liste.
- Sélecteur entre le français et le tamazight affiché en caractères tifinaghs.
- Mémorisation de la langue choisie entre les ouvertures de l’application.

## Lancer l’application

Depuis le dossier du projet :

```powershell
ns run android
```
