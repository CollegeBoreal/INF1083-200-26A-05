# B300155909 – Application NativeScript

Projet NativeScript avec Angular : une liste de cinq personnalités africaines et une page de détails pour chacune.

## Démarrage

Depuis le dossier `B300155909` :

```bash
npm install
ns doctor
ns devices
ns run android
```

Sur macOS avec Xcode installé et configuré :

```bash
ns run ios
```

Dans l'assistant initial de NativeScript, le projet de référence du cours utilise Angular et le modèle Hello World. Ce dossier contient les fichiers du projet déjà préparés.

## Fichiers principaux

- `src/app/people/person.service.ts` : données des cinq personnalités.
- `src/app/people/person-list.component.html` : écran de la liste.
- `src/app/people/person-detail.component.html` : écran de détails.
- `src/app/app.routes.ts` : routes de navigation.
