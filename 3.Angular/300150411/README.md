# Labo 3 — Introduction à Angular

**Étudiant :** 300150411  
**Cours :** INF1083 — Développement d'applications

## Objectif

Découvrir Angular et apprendre à créer une première application web. Comprendre les composants, la liaison de données, les événements, les directives, les API REST et le routage.

## Étapes réalisées

1. Installation de Node.js et d'Angular CLI :
   `npm install -g @angular/cli`

2. Création du projet :
   `ng new B300150411`

3. Démarrage du serveur :
   `ng serve` → http://localhost:4200

4. Création du composant accueil :
   `ng g c accueil`

5. Liaison de données : affichage d'un titre avec la variable `titre` et `{{ titre }}`.

6. Événement : création d'un bouton avec `(click)` qui appelle la méthode `saluer()`.

7. Directives : utilisation de `@if` et `@for` pour afficher du contenu et une liste.

9. Routage : découverte des routes Angular et utilisation de `<router-outlet>`.

10. Style CSS : ajout de styles pour améliorer la présentation de l'application.



## Conclusion

Ce laboratoire m'a permis de découvrir Angular et de comprendre comment créer une application web avec des composants. J'ai également découvert la liaison de données, les événements, les directives et le routage.
